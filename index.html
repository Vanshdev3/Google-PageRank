The Problem: Search Engines Before Google

Before Google, search engines ranked websites by counting words. If you searched "Math", the website with the word "Math" written 1,000 times was ranked #1. Larry Page and Sergey Brin realized that a hyperlink is like a "vote". If Page A links to Page B, A trusts B. They turned the internet into a Matrix, and used Eigenvalues & Eigenvectors to find which pages had the most authority.

Final PageRank (The Eigenvector)

The PageRank vector is the Eigenvector corresponding to the Eigenvalue of 1 of the Google Matrix.

    Step 1: Adjacency Matrix (A)
    Structure of the web. 1 if linked, 0 if not. (Columns = From, Rows = To)
    Step 2: Stochastic Matrix (S)
    Divide each column by the number of outgoing links (Probabilities).
    Step 3: Google Matrix (G)
    Adding the 85% "Damping Factor" to handle random internet surfing.
